# 📸 Папка для изображений бота

## 📁 **Требуемый файл:**
- `hellonightvpn.png` - главное изображение для приветствия

## 📋 **Инструкция:**
1. Поместите файл `hellonightvpn.png` в эту папку
2. Рекомендуемый размер: до 1280x1280 пикселей
3. Формат: PNG, JPG или JPEG
4. Бот автоматически изменит размер если нужно

## 🎯 **Использование:**
Изображение будет отображаться в:
- Команде `/start`
- Кнопке "Меню" 
- Главном меню

## ⚠️ **Важно:**
- Файл должен называться точно `hellonightvpn.png`
- Если файл не найден, бот отправит обычное текстовое сообщение
